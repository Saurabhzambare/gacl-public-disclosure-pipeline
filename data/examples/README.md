# Reviewed example outputs

These two small CSVs were generated by the actual local pipeline on 19 November 2026 and reconciled against the cited official PDF tables.

- monthly_site_observations.csv: 6 monthly average freshwater observations, KL/day.
- annual_company_observations.csv: 12 standalone company annual totals, GJ or KL.

They include raw/normalized values, report URL, PDF/printed pages, scope and document checksum. They are a convenient preview, not fabricated training data and not a replacement for rerunning the pipeline.

FY 2024–25 comparative BRSR disclosures are the recalculated figures in the FY 2025–26 report. Printed pages 79–80 describe the reporting-boundary/methodology alignment and revised water-consumption calculation. Preserve this context in year-over-year comparisons.

No raw PDF is committed. Download official reports through the pipeline.


## Reviewed-extract input mode

Use --from-examples when the report website is unavailable. It validates the pinned repository CSV snapshots, runs the normal data checks and loads the warehouse without downloading PDFs. Run history and data/processed/run_manifest.json record input_mode=reviewed_extracts and pdfs_verified_this_run=false. This is distinct from --offline, which verifies cached source PDFs. The 22-test suite includes no-network execution, duplicate-safe reruns, altered-snapshot rejection, Windows newline handling, certificate failure handling and migration of existing run history. See docs/HTTPS_TROUBLESHOOTING.md from the repository root.
